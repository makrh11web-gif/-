# 便利屋さまLP案件（応募用）

## 案件の要点
- 依頼：街の便利屋の、問い合わせを増やすためのLP制作（デザイン・コーディング・レスポンシブ）
- 素材：ワイヤー・ラフは相談、画像・文章はおおむね制作側で用意、サーバー・ドメインなし
- ターゲット：20〜40代女性／雰囲気：安心
- 参考サイト：https://tatebayashi.benriya-family.com/ （複数ページのHP）
- 納期：12月初め／予算：8〜15万円（税抜）

## 提案用デモ（架空の便利屋「まちの便利屋 ひとてま」）
- LP版：https://rootpage-site.vercel.app/works/benriya-lp/
- HP版（5ページ）：https://rootpage-site.vercel.app/works/benriya-hp/
- 検索には出ない設定（noindex）。店名・電話番号・料金・お客様の声・スタッフはすべて架空。

### 設計の考え方（応募文・打ち合わせで説明に使う）
1. **女性の「家に来てもらう不安」を先回りして消す**：女性スタッフ指名OK、身分証提示・制服、損害賠償保険、作業前見積り＆キャンセル無料を、最初の画面と「安心の理由」で繰り返し見せる。
2. **「こんなこと頼んでいいの？」の心理的ハードルを下げる**：「電球1つから」「小さなことでも」をキャッチと吹き出し・FAQで伝える。
3. **料金を先に見せる**：基本料金・出張費0円・見積り無料＋作業別の目安を表で明示。
4. **問い合わせ手段を3つ用意し、スマホでは常に画面下に固定**：電話・LINE（写真を送るだけ見積り）・フォーム。フォームで「女性スタッフ希望」を選べる。
5. **色と書体**：クリーム×セージグリーン（安心）＋コーラル（ボタン）、丸ゴシックでやわらかく。

## 受注後にクライアントへ確認すること
- 屋号・ロゴの有無、対応エリア、営業時間、料金表（実際の価格）
- スタッフ写真や作業写真の有無（なければ撮影の相談 or 素材で対応）
- LINE公式アカウントの有無（なければ開設の手順を案内）
- お問い合わせの受け取り先（メールアドレス）、フォームの送信サービス
- ドメイン名の希望、サーバー（静的サイトならVercel/Cloudflare Pages等で安価に運用可能。商用利用可のプランを選ぶ）
- 口コミ・お客様の声として掲載してよい実例があるか
