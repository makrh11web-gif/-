## 対応可否の判断

**対応可能。応募を推奨。**

- 工程（デザイン・コーディング・レスポンシブ）は `harness/website-projects.md` の技術方針（静的HTML/CSS/JS）にそのまま合致。
- 金額レンジ（8〜15万円）は `knowledge/web-side-business.md` のスタンダードプラン想定（¥98,000〜）の中〜上振れで、
  画像・文章の作成まで引き受ける分の工数を織り込んでも妥当。**提案額は¥110,000〜¥130,000程度**を軸に、
  ヒアリング後に確定させる想定で応募するのが無難。
- 唯一の懸念は「画像・文章を概ねお願いしたい」＝写真素材が別途必要になる可能性。実店舗の写真がない場合、
  有償ストックフォトの購入費用を見積りに含めるか、先方に最低限（外観・スタッフ等）の写真提供を依頼する必要がある。
  この点は応募メッセージで明示的に確認する。

## デザイン方針（オリジナル要素）

- ターゲット（20〜40代女性・安心感）に合わせ、便利屋業界にありがちな「工具・作業服」的なゴツさを避け、
  丸みのある書体（Zen Maru Gothic）・パステル寄りのテラコッタ＋セージグリーン配色・角丸カードで
  「話しかけやすさ」を演出。
- 業界共通の弱点である「知らない人を家に呼ぶ不安」に正面から向き合うセクション（安心して任せられる理由）を
  参考サイトより明確に独立させ、FAQでも同じ不安に重ねて回答する二段構えにした。
- 写真素材がない前提のため、ヒーローや作業内容カードは線画イラスト（SVG）とアイコンで構成し、
  「素材待ちのプレースホルダー」に見えないよう仕上げた。実際の受注後は外観・スタッフ写真に差し替える。

## 技術

- 静的HTML/CSS/JS 1ファイル（`index.html`）。ビルド工程なし、そのままどこにでもデプロイ可能。
- フォント: Google Fonts「Zen Maru Gothic」
- レスポンシブ: 1040px / 780px 前後をブレークポイントに、ハンバーガーメニュー・モバイル下部固定CTAあり
- Playwright（Chromium）でデスクトップ幅・モバイル幅（390px）の表示、ハンバーガーメニューの開閉、
  FAQアコーディオンの開閉を目視確認済み。
