クライアント資料「ココクリーン LP改修 指示書」（全9ページ）の構成①〜⑪に沿って作成した。

- 成果物: `index.html` ＋ `images/`（写真11点）。外部依存はGoogle Fontsのみ

  v1（ティール×オレンジ・イラストのみ）は git 履歴に残っている

  デザイン（配色・ロゴ）は新規で作成。受注後は既存サイトのロゴ・トーンに合わせて調整する。

## 指示書チェックリストへの対応状況

| 指示書の項目 | 対応 |
|---|---|
| 「コロナ」「除菌」「消毒」で全ページ検索してゼロ | ✅ 0件（コメント含む） |
| 「一般廃棄物」「一廃」で全ページ検索してゼロ | ✅ 0件 |
| 静岡の産廃許可が入っている | ✅ ⑧に愛知・岐阜・静岡を掲載 |
| 電話ボタンが画面内・追従で表示される | ✅ FV内（375×667でスクロールなしで見える）＋スマホ下部に追従バー |
| 現場の生々しい写真がない | ✅ 整った室内・作業員（汚損部なし）・建物などのイメージ写真のみ |
| 金額が書かれていない | ✅ 「円」0件。⑦は無料の現地確認・お見積りのみ |
| 管理会社・大家向けセクションがある | ✅ ⑨。「法人のお問い合わせはこちら」→フォームに法人フラグ |
| フォームのテスト送信が届いた | ⏳ 送信先未接続（受注後に接続） |
| 電話タップの計測が動いている | ⏳ `tel_tap` イベント実装済み。GA4/広告タグIDは受注後に設定 |

その他の指示への対応:
- サイト名は「ココクリーン」のまま、サブタイトルを「特殊清掃・原状回復」に変更
- 実績数・事例は掲載なし（新規立ち上げ扱い）
- 「完全に消えます」等の断定表現なし、薬剤名・工法名なし
- 持っていない民間資格は掲載なし
- ⑤ご依頼の流れの「6. その後のご相談」（不動産への導線）を強調表示
- ⑥の車両・早朝夜間は【要確認】のため、指示書どおり「ご希望に応じて配慮」「ご相談ください」の表現に留めた
- フォームは4項目のみ（お名前・電話番号・所在地（市区町村）・状況）、送信完了画面あり、スマホで約1画面
